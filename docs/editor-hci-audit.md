# Editor interaction audit

The review follows [Shneiderman's Eight Golden Rules](https://www.cs.umd.edu/users/ben/goldenrules.html) and [Nielsen's usability heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/). This is a heuristic review, not a study with customers.

| Principle | Applied change or retained behavior |
| --- | --- |
| Consistency | Palette presets and custom paper color are presented as two ways of changing the same paper. Custom color clears the preset selection indicator. |
| Universal usability | Existing keyboard crop controls, native form controls, touch dragging, reduced-motion preferences, and responsive layout remain available. |
| Informative feedback | An uploaded-photo count and private-storage message replace the empty upload prompt. Preview changes and save feedback remain visible. |
| Closure | Uploaded photos move into a compact manager; upload/search panels return only for an explicit add or replacement action. |
| Error prevention | Size/finish use supported product options. Existing decoded-file, ownership, DPI and print-text checks remain unchanged. |
| Reversal | Existing undo/redo remain available. Starting a photo change can be cancelled before an upload. |
| User control | Photo-only presentation choices were removed from the editor. Physical frame size and finish can be changed next to the preview. Previously saved layouts and ordered designs are retained. |
| Reduced memory load | Thumbnails identify the photos already added. Crop adjustments use progressive disclosure. Related paper-color controls sit in one group. |

## Visual refinement

The oak surround uses smooth tonal shading and an inset edge rather than prominent repeating stripes. Soft shadows add depth while the controls remain flat and quiet. A4 and A3 show different preview widths, matching their relative physical size. The product's existing provisional materials and pricing are unchanged.

## Checks

Verify both empty and uploaded states, explicit add/change/cancel actions, palette/custom-color feedback, A4/A3 dimensions and price changes, draft saving, and responsive overflow. Existing customer assets, proof approvals and payment/shipping gates are unaffected.
