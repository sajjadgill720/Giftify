# Quranic ayat and Ahadees collection

Two additive template IDs, `quran` and `hadith`, reuse existing private drafts, editor, frame/size settings, text positioning and order flow. Both require words mode; retained photos are not rendered. The homepage has a dedicated collection section and shop filter. Samples are labelled text-layout placeholders, not religious quotations.

Customers supply their passage and source. `memory.narrative` stores the passage (220 characters), `memory.names` stores its reference (48 characters). Print checkout requires a non-empty reference; this does not verify the source or authenticate a hadith. Exact wording, diacritics, citation, and any translation require review by a qualified person before production. No religious text is generated or automatically inserted.

Arabic/Urdu drafts remain previews. Existing non-ASCII print validation is preserved; checkout/export for Arabic remains blocked pending licensed embedded fonts, shaping, diacritic layout, and inspected print samples. Long passages need a future expanded layout. No claim of authenticating religious text is made.
